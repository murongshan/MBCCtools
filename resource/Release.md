## 1.6.0 (2026-11-17)

官服日常分支的首个公开发布，重点是把「夜莺助手日常」做成可直接运行的完整包。

### ✨ 新增

- **夜莺助手日常**：新增「助手待办（官服试验）」任务，从主页打开夜莺助手，依次处理体力专属补给、监管生产物资、监管事件、记忆风暴、派遣、秘盟捐赠、浊暗之阱、每日免费补给、友情点、监察每日活跃十项。
- **登录恢复**：情绪检测正文/完成识别、储备体力弹窗、局长生日礼物与贺信、未知弹窗领取与关闭、主页图标 + 管理局 + 助手模式三级确认。
- **助手快捷浮层**：识别「前往」浮层后按目标页直达对应业务节点；无法识别时关闭浮层回面板；监察奖励延后处理。
- **补充事务**：助手「收到新邮件」、成就一键领取、友情点「当前无可领取」状态。

### 🐛 修复

- 狄斯币入口新增「清剿行动」「常态记录」分支，兼容新版界面路径。
- 监管「开始按钮」增加点击偏移与失败重试。
- 邮箱入口增加画面稳定等待与入口复查，减少重复点击。
- 助手列表滚动、返回主页与面板复查的稳定性调整。

### ✅ 验证

- 2026-11-13 至 11-17，官服 MuMu 的 AUTO-MAS「无期迷途日常」队列连续五个游戏日成功；11-17 完整日志结束于「体力低于30，助手仅剩长期任务」。
- 49 个 Pipeline JSON、引用完整性与三服资源加载检查通过。
- 发布包使用包内 Python 与 MaaFw 5.12.3，用户无需自备 Python。

### ⚠️ 已知限制

- 本次 Release 仅提供 Windows x64 / arm64 包；macOS 构建因 GitHub runner 连续不可用而暂缓，待恢复后补发。
- 仅官服 MuMu 实测；B 服、国际服与 macOS 未做同等业务验证。
- 2026-11-12 的手工回归曾在「使用储备体力」弹窗上失败；日常队列这几天未再遇到，该场景仍待实机确认。
- 「秘盟兑换」Pipeline 保留在仓库中，但 GUI 任务列表暂未开放；「活动大厅领奖」仍是未启用草稿。
- 本 fork 不提供 MirrorChyan 更新通道，升级请从本仓库 Releases 覆盖安装。
