关于更新

### 更新方式

本 fork 不接入 Mirror酱，更新统一从 GitHub Releases 获取。

🌏 **GitHub Releases**

- 下载最新 `MBCCtools-win-x86_64-*.zip`
- 解压后覆盖原安装目录即可，个人配置、日志与 `record/` 不会被仓库覆盖

📦 **手动更新**

- 如果覆盖后出现异常，建议备份 `config/` 与 `record/` 后重新解压一份完整包
- 本 fork 不提供自动更新与版本检查，升级以 Releases 页面的最新版本为准

> 下载页：<https://github.com/murongshan/MBCCtools/releases>
