# 官服 MuMu 开发快照

本分支在 [quietlysnow/MBCCtools](https://github.com/quietlysnow/MBCCtools) 的 v1.5.2（`d7dfbab`）上继续开发，保留上游归属与许可证。本页记录截至 2026-10-29 的本地开发状态；源码快照包含尚未完成验收的功能，不代表稳定发行版。

## 技术与运行范围

- 主流程采用 JSON Pipeline 和 ProjectInterface V2；复杂扩展沿用 Python Agent。
- 已验证的引擎组合为 MaaFramework / MaaFw 5.12.3，配合 MFAAvalonia GUI 2.16.1。Agent 与 GUI 原生库需保持兼容版本。
- 实机验证范围为官服、Windows x64、MuMu。识别坐标以 1280×720 为基准，框架负责截图归一化。
- GUI 源码另属 MFAAvalonia-MBCC 项目，本仓库管理游戏资源、流程、Agent 与接口配置。

## 只读资源检查

在仓库根目录安装依赖并执行：

```sh
python -m pip install -r requirements.txt
python tools/检查资源.py
```

工具默认读取本仓库的 `resource/` 和 `interface.json`，使用已安装 MaaFw 自带的原生库，结果写入已忽略的 `.scratch/resource-check/检查结果.json`。它检查 JSON、节点与模板引用、接口覆盖，并真实加载官服、B 服和国际服资源；不会连接模拟器或执行游戏任务。

要指定其他资源副本或与 GUI 相同的原生库，可使用：

```sh
python tools/检查资源.py --resource-root /path/to/resource --interface /path/to/interface.json --native-library-root /path/to/native
```

检查通过不证明 OCR 准确率、坐标适配、领奖到账或 GUI 队列正确。该工具不移动 `resource/default_pipeline.json`，因此不会改变现有默认参数的生效范围。
